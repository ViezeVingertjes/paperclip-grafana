## [1.0.0] - 2026-10-30

First release: the Paperclip dashboard (health, overview, runs, startup and first token, agent turns and tools,
providers, workspace, controller, budget, API and database, chat channels, traces), built on Paperclip's traces only
(span metrics plus TraceQL metrics), with a *Instance* variable, a Podman + systemd installer and a Docker Compose file.

### Added
- `dashboards/paperclip.json`, generated by `tools/gen_dashboard.py`.
- `paperclip-otel/`: a Containerfile that adds Paperclip's exact-version OpenTelemetry packages to a Paperclip image, and
  `apply-paperclip-otel.py`, which adds the export variables to an env file.
- `install.sh` (Podman Quadlet on a shared `paperclip-net` network), `docker-compose.yml`, `tools/import_dashboard.py` for an existing Grafana.
- `tools/validate_dashboard.py` (runs every query, including TraceQL metrics), `tools/send_sample_telemetry.py` (CI only),
  unit tests and CI, `examples/alerting/`.
